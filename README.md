# 奇幻冒险图鉴 🐉

一份不太严肃的西式奇幻生物图鉴：龙、精灵、恶魔、矮人、兽人、巫师、巫妖、哥布林、吸血鬼，外加冒险者委托告示板与生存须知。暗色极简 + 动效设计，单文件零依赖。

## 在线访问

| 入口 | 地址 | 说明 |
|---|---|---|
| GitHub Pages（推荐） | https://reaor.github.io/afuntry/ | 需先启用一次，见下方 |
| raw.githack 镜像 | https://raw.githack.com/Reaor/afuntry/main/index.html | 即开即用 |

## 启用 GitHub Pages（仅需一次，约 10 秒）

1. 打开仓库 **Settings → Pages**（直达：<https://github.com/Reaor/afuntry/settings/pages>）
2. **Source** 选择 *Deploy from a branch*
3. **Branch** 选择 `gh-pages`，目录 `/(root)`，点 **Save**
4. 等待 1–2 分钟，访问 <https://reaor.github.io/afuntry/>

此后每次推送，`.github/workflows/deploy-pages.yml` 会自动把最新页面发布到 `gh-pages` 分支，Pages 随之更新。

## 本地预览

直接用浏览器打开 `index.html` 即可。
